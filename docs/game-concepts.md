# PAPERHOOD 第二款游戏：备选玩法

> 讨论记录；均未定案、未进入开发。延续 PAPERHOOD 的纸艺兜帽角色、深绿色山城、折纸材质和荧光绿点缀，但新游戏应与现有跳跃／滑翔跑酷明显不同。若游戏成绩影响实际 Token 发放，奖励规则与服务端验分需单独设计，不能直接信任客户端分数。

## 1. 纸飞机空中收集（备选）

- 纸飞机是飞行中的主角，而非从地面弹射几次的抛物线关卡。
- 玩家操纵飞行路线，收集 Token 图标计分；途中有障碍与追逐的敌人。
- 不同级别逐步引入不同方向与强度的风：顺风加速、逆风减速、侧风改变航向。风向需提前以纸屑、飘带等明确提示，避免不可预判的撞击。
- 安全航线提供普通收集物；高价值收集物靠近风险区域。连续收集可形成倍率，受伤中断连击。追兵施压，但应能借风流甩开。
- 核心区别于现有跑酷：可主动选择／修正空中路线，以风和惯性为主要技巧，而不是只把地面跑酷搬到空中。
- 开放问题：飞行视角、操纵方式、每局时长与关卡评分尚未确定。此前生成的“地面弹射”概念图不代表这个版本的最终玩法。

## 2. 单角色开门救援（备选，暂不深入）

- 俯视角，小房间与门后的未知信息；敌人的视野范围可视化，玩家观察巡逻、潜行、开门、保护人质并消灭敌人。
- 只操纵一个角色，不做复杂小队指挥。窥视门后的次数有限，门外线索应与实际情况一致，避免纯猜谜。
- 用房间模板及可验证的变化组合布局、敌人、人质、巡逻与视野，减少背板；刷新不能重置同一局的窥视资源。
- 目前仅作为方向保留，不继续细化。

## 3. 横版「短腿越长越难走」（新提案，待讨论）

- 纸艺小人开局腿很短，沿横向关卡前进时收集“腿部纸片／折纸腿节”，腿逐渐变长。
- 长腿可以跨越更宽的缝隙、够到更高的收集物，也让步幅和重心更难控制；成长同时带来优势与风险。
- 游戏乐趣应落在每一步的控制和失衡恢复，而不是复用现有游戏的自动前进、跳跃、滑翔跑酷。
- 可探索“交替迈步”或“按住抬腿、松手落脚”的轻量手机操作；尚未确定，需要先验证是否顺手。
- 视觉上腿可以是层层接长的折纸腿节，保持兜帽角色的辨识度。注意设置合理长度上限、摄像机跟随及低矮障碍，避免后期画面和碰撞失控。
- 开放问题：具体控制方式、失误惩罚、计分是距离还是拾取物，以及腿长是否可在一局中缩短，均待原型验证。
