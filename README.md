# PAPERHOOD · Paper Run

独立的 TypeScript + Vite 跑酷原型，仅保留 Canvas 2D 纸艺版。当前仅为练习版，不替换 web 内置游戏，不提交分数，不请求账号信息。

## 纯 2D 版本

已移除 3D 入口、模型、渲染器及 Three.js 依赖。旧链接中的 `view=2d` / `view=3d` 参数均忽略，统一显示 2D；`?seed=42` 仍可用于固定路线。New route 仍生成新种子。

`src/paper2d.ts` 只读取模拟状态，不修改游戏数据或消耗地图随机数。玩法继续共用固定时间步、输入记录、三格生命和 90 秒局长。

## 开发

### iframe 嵌入布局

入口加 `?embed=1`（可继续追加 `&seed=42`）启用纯游戏布局：隐藏站点标题、Logo、页脚、路线编号和重复操作说明；游戏和底部操作按钮填满 iframe。保留 HUD、音效、暂停、开始/结算弹层和练习声明。父页面需给 iframe 明确宽高，例如 `width:100%;height:600px;border:0`。不带该参数仍是独立演示页面。

`embed=1` 只切换布局，不包含平台认证、通信或成绩提交；这部分后续通过 Bridge 接入。

Node.js 22；在此目录执行：

```sh
npm ci
npm run dev
npm test
npm run build
```

开发地址 `http://127.0.0.1:5190`，使用固定端口，不占用 web 的 5173 或 admin 的 5180。编译产物 `dist/` 可独立静态托管。没有必须填写的环境变量。

## 操作

### 定稿美术接入

最新 2D 背景已拆成独立的远山天空和透明城堡两层卷轴（0.045× / 0.2× 地面速度），底部增加 1.12× 速度的透明纸艺植被。植被仅覆盖底部 16%，月亮固定，暂停冻结；减少动态效果设置下停止装饰卷轴。素材目录仍为 `public/art/`，旧单层全景仅保留作为源素材参考，不再加载。

2D 默认使用 `public/art/` 中的生成素材：透明角色身体、独立透明披风、无月亮的城堡远景、折纸纹理。披风分条采样、围绕肩部摆动并平滑展开，身体随滑翔轻微前倾；不是完整逐帧动画。城堡镜像循环，近景纸山独立视差，月亮独立绘制以避免循环出现双月；平台纹理裁剪/重复铺设，不改变碰撞宽高。红色障碍和纸钞仍按规则几何绘制，并叠加纸张纹理。

素材加载期间开局按钮显示加载状态；任一图片失败或 12 秒超时，恢复可玩状态并提示轻量美术降级，刷新可重试。当前保留高分辨率 PNG，后续可优化体积；角色/场景均为内置图像生成工具制作，不影响游戏分数可信度或服务器协议。美术生成说明见 `docs/art-direction.md`。

- 点击画面、底部按钮或按空格跳跃；持续按住在下降时滑翔，松开加速下落。
- Esc 或右上角按钮暂停；切换窗口/隐藏页面自动暂停，需要手动恢复。
- 3 次受伤机会，掉落救回前方平台；受伤后短暂无敌。
- 连续收集提升倍率，每 24 张纸钞提供 2.5 秒免伤和邻近纸钞吸附；HUD 显示触发进度。
- 高处浅色纸钞基础分 200，下方绿色纸钞基础分 100；下方路线容错较大，但出口也需要跳跃。低顶通道需要先跳、松开滑翔从顶棚下通过，再起跳。
- 右下角可关闭合成音效，音效只在开始游戏后启用。减少动态效果的系统设置会禁用受伤震屏和设备振动。
- 存活 90 秒通关。新一局使用随机种子；结算可选择重玩相同路线。

## 结构与边界

- `src/simulation.ts`：固定 60Hz 时间步、种子生成、碰撞、计分、输入记录，与渲染无关。
- `src/main.ts`：渲染、输入、暂停、结算和响应式镜头。
- `src/simulation.test.ts`：种子稳定性、生成边界、回放、跳跃与计分测试。

第二版包含跳跃、长沟滑翔、高低路线、低顶通道、缓冲五类路段，保留原有跳跃和滑翔参数。前约 15 秒使用简单路段，随后轮换布局；15/40/70 秒有阶段提示和背景色渐变。已补充收集音效与纸屑、受伤闪红/轻微震屏、披风平滑展开。仍使用占位美术，尚不是完整的 15–20 种片段库或精调后的排行榜难度。测试涵盖多种子的几何约束、跨沟运动、上下层落地和顶棚碰撞，不代表完整真机验收或所有组合的自动通关证明。

第三版难度调整：保持原有速度曲线、跳跃和滑翔参数、三格生命与受伤保护。前约 15 秒保留单障碍热身；中段加入双连跳；后段出现三连跳、减少缓冲段，最后约 20 秒不再分配空白缓冲段。长沟后的落地要衔接跳跃，低顶段为「跳—落地—穿过顶棚—再跳」。难度分区按地图距离确定，掉落救回可能让分区稍提前，HUD 阶段仍按局内时间显示。

第四版加入主路线高度变化：每四段中的两段改变高度，单次高差 0.9；上升段缩短缺口至 1.8–2.5，下降/平路保留原来的缺口范围。障碍、纸钞、支线高台相对主平台放置；掉落恢复使用实际平台高度。镜头缓慢跟随主地形高度，不跟随角色跳跃，并在暂停时冻结。

第五版进一步加密后半程：315 距离单位之后每个主平台都改变高度，取消空白缓冲段。中后段双连跳平台缩短为 24–26，末段三连跳平台缩短为 32–34，尖刺间距从 9 缩短为 8；长沟落地后改为连续两次跳跃。保留单步高差 0.9、原有跳跃参数和至少 7.5 的落地入场空间，不在缺口边贴脸放障碍。

18 项测试中包含 30 个种子的全局无护盾、无拾取、无伤 90 秒通关操作样例，以及最高速度平台组合、高度边界、跨高度跳跃、非零高度掉落恢复检查；这证明所测种子有可行路线，不代表穷尽所有种子或真人难度已调平。

当前规则版本 `paper-run-practice-v5`。随机种子由浏览器生成，成绩完全不可信；固定步长并不自动保证跨语言计算一致性。正式接入前需要服务端签发局次与种子、冻结规则、实现 Go 对应验分与跨语言回放样例。现有外部 H5 通信测试脚本仅验证通信，不能代替正式计分协议，因此这里没有伪装成已接入的分数消息。

本项目不包含登录凭证、服务端密钥或钱包操作。无需 Unity 或额外编辑器。角色及场景使用纸艺图像素材与 Canvas 2D 渲染。
